# Script

確認した事実から、自然に視聴できる構成と日本語台本を作る。

## 正本

- `project.json` を案件固有の構成、シーン順、ナレーション、shot、納品設定の正本にする。グローバル既定値は `style.json` に置く。
- 承認時は `project.json` の内容をそのまま提示する。別の台本成果物を正本や標準成果物として作らない。
- `research.md` は調査内容の整理に役立つ場合だけ参照する。

## 台本

- 冒頭の引き、情報の優先順位、結論を明確にし、同じ説明や内容の薄い水増しを避ける。
- 指定尺は構成量の判断に使い、尺合わせだけの追加、削除、言い換え、再生成をしない。
- ナレーション本文を字幕本文としてそのまま使う。改行と表示タイミング上の分割だけを後工程で変えてよい。
- 各シーンは一つ以上の `shots` を持つ。素材選定後、各shotにレンダーで使う `path`、`type`、必要な `source_start`、`duration_seconds`、`motion` を記録する。

## 掛け合い

「掛け合いの動画」では `zundamon` を解説役、`metan` を視聴者目線の聞き役にする。機械的に交互発話させず、疑問、驚き、確認、短い要約、自然なツッコミが理解やテンポに効く地点だけへめたんを置く。各発話に `speaker_key` を付ける。
