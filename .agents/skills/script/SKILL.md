# Script

調査済みの事実から、自然に視聴できる構成と短い日本語台本を作る。

## 正本

- `project.json` を構成、シーン順、ナレーション、shot計画の正本にする。
- `script.md` は承認用に必要な場合だけ `project.json` から作る。手作業で別内容を持たせない。
- `research.md` の事実を台本へ写しすぎず、出典メタデータは `sources.json` に置く。

## 台本

- 冒頭の引き、情報の優先順位、結論を明確にし、同じ説明や内容の薄い水増しを避ける。
- 指定尺は目安として構成量の判断に使う。完成尺を合わせるためだけの追加、削除、言い換え、再生成をしない。
- ナレーション本文を字幕本文としてそのまま使う。`subtitle` の別文は持たせない。改行と表示タイミング上の分割だけを後工程へ許す。
- 各シーンは一つ以上の `shots` を持ち、各shotに短い `visual_intent` を付ける。素材パスと出典IDは承認後の選定で追記してよい。

## 掛け合い

「掛け合いの動画」では `zundamon` を解説役、`metan` を視聴者目線の聞き役にする。機械的に交互発話させず、疑問、驚き、確認、短い要約、自然なツッコミが理解やテンポに効く地点だけへめたんを置く。各発話に `speaker_key` を付ける。
